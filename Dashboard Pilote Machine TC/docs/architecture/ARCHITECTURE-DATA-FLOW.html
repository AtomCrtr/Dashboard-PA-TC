Du signal terrain à la décision machine

Lecture de l’architecture Google Sheets, Drive et Apps Script, avec les frontières de responsabilité, les transformations, les tables persistantes et les points de contrôle audités.

État observé : 27/08/2026 Périmètre : PA STR · perçage Source NC officielle : Données NC PA

Contrats visibles dans le flux

  • Entrées métier. Le master, les remontées production et Données NC PA sont lus depuis Google Sheets sans réécriture des feuilles sources.
  • Import MES. Drive reçoit les CSV, XLSX ou Google Sheets. Le script classe les événements PA, sépare ALEA_MES et NC, puis alimente STG_MES et la file NC_MES_PREVISIONNELLES.
  • Consolidation. Le périmètre est PA/PA STR et catégorie Perçage quand l’identité master est exploitable. Les faits portent la source, l’IMMO, la famille, la qualité du rapprochement, la durée et le poids.
  • Sorties persistantes. FAITS_IMMO porte les faits actifs, FAITS_IMMO_ARCHIVES la rétention, CONTROLES les anomalies, JOURNAL_IMPORT la traçabilité des fichiers et les trois tables MFT_* le plan officiel.

Risque de gouvernance

Le manifeste autorise le domaine mais exécute sous USER_DEPLOYING. Les rôles affichés dans le workflow NC et les boutons du site ne remplacent pas une autorisation serveur. Le contrôle d’accès par rôle est le prérequis avant une diffusion large.
